## ✅ 1 - NumPy (Completed)

**NumPy** is the foundation of the entire Python data science ecosystem. Every other library — Pandas, Matplotlib, Scikit-learn - is built on top of it.

### 🧩 Topics Covered

```
✅ Introduction          - What NumPy is and why it's 10–100× faster than lists
✅ Creating Array        - Creating 1D, 2D, MultiD array
✅ Basics                - ndarray, dtypes, factory functions, attributes
✅ Indexing & Slicing    - Basic, fancy, boolean — view vs copy
✅ Reshaping             - reshape, ravel, flatten, stack, split
✅ Array Modification    - clip, sort, argsort, unique, pad
✅ Broadcasting          - Rules, row normalisation, vectorisation
✅ Missing Values        - NaN, nan-safe functions, imputation strategies
✅ Statistics            - Aggregation, percentiles, correlation, histogram
✅ Linear Algebra        - matmul, solve, eigenvalues, SVD, regression
✅ Capstone Project      - Full student analytics pipeline
```
