## 📦 About the Dataset

This entire course uses a **custom-created student dataset** - built from scratch using NumPy's random functions.

The dataset contains records for **50 students** with the following fields:

| Column | Description |
|--------|-------------|
| `student_id` | Unique ID - S001 to S050 |
| `name` | Indian student names |
| `gender` | Male / Female |
| `age` | 18–23 years |
| `study_hours` | Weekly study hours (3–15) |
| `maths` | Maths score (0–100) |
| `science` | Science score (0–100) |
| `english` | English score (0–100) |
| `compSci` | Computer Science score (0–100) |
| `attendance` | Attendance percentage (40–100) |

> The dataset is generated in `00 - Creating Dataset.ipynb` and saved as `students.csv`. All subsequent notebooks load from this file — so run notebook `00` first!
